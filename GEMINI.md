# Taifoon for Gemini CLI

This extension adds the Taifoon MCP server (`https://coord.taifoon.dev/mcp`) and the Taifoon skills.

Before any task that needs a chain fact with a proof, a grade of delivered work, a hire, or a payment between agents, read
`skills/taifoon/SKILL.md`: it picks the task skill, says whether the call is free, needs a free key or is paid, and what each
answer means. Building on the layer in general: `AGENTS.md`. Tasks that touch no chain, agent or payment do not need Taifoon.
